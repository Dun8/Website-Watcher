# Website Watcher

Приложение отслеживает изменения на сайтах. Добавляете сайт через API, приложение само проверяет его по расписанию,
сохраняет историю проверок в PostgreSQL и присылает сообщение в Telegram, если содержимое изменилось.

JavaScript не исполняется: отслеживается только то, что есть в HTML, который отдаёт сайт.

## Запуск

1. Создайте базу данных в PostgreSQL и выполните `backend/app/database/schema.sql`.
2. Скопируйте `.env.example` в `.env` и заполните его.
3. Установите зависимости и запустите сервер из папки `backend`:

```bash
pip install -r requirements.txt
cd backend
uvicorn app.main:app
```

Запускайте один процесс Uvicorn (без `--workers`), иначе у каждого процесса будет свой планировщик.
Swagger: http://127.0.0.1:8000/docs

## Telegram

1. Создайте бота через `@BotFather` и получите токен.
2. Напишите боту `/start`.
3. Узнайте `chat_id`: откройте `https://api.telegram.org/bot<TOKEN>/getUpdates`, значение в `message.chat.id`.
4. Впишите `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в `.env`.

`.env` не должен попадать в Git.

## Endpoints

| Метод | Endpoint | Что делает |
|---|---|---|
| GET | `/health` | Проверка приложения и PostgreSQL |
| POST | `/api/websites` | Добавить сайт |
| GET | `/api/websites` | Список сайтов |
| PATCH | `/api/websites/{website_id}` | Изменить название, CSS-селектор, интервал, `is_active` |
| POST | `/api/websites/{website_id}/check` | Ручная проверка |
| GET | `/api/websites/{website_id}/check` | История проверок |

Если `css_selector` не указан, проверяется вся страница. `"css_selector": null` в PATCH убирает селектор.
Интервал по умолчанию 60 минут, минимум 5.

## Как это работает

- Первая успешная проверка сохраняет исходное состояние (`has_changed = null`), уведомления нет.
- Дальше новый хеш сравнивается с хешем последней успешной проверки: `false` - без изменений, `true` - изменилось, приходит сообщение в Telegram.
- Ошибка сайта (тайм-аут, 404/500, не HTML, не найден селектор) сохраняется в историю как неудачная проверка. Хеш последней успешной проверки она не заменяет.
- Ошибка Telegram только выводится в консоль, проверка остаётся сохранённой.
- Планировщик каждые 30 секунд смотрит, каким сайтам пора проверяться.

## Ограничения первой версии

- Нет защиты от SSRF (запросов на внутренние адреса) и ограничения размера ответа: запускайте только локально или в доверенной среде.
- Нет повторной отправки уведомлений.
- Нет авторизации, один Telegram-чат.
